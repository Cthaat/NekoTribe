# 群聊频道管理

创建、编辑和删除频道使用共享会话鉴权。路径 ID 必须是正十进制安全整数。只有启用且未删除群组的群主、管理员和版主可以管理频道，活跃和禁言成员使用相同的管理角色规则。频道不存在、已删除或当前用户无管理权限时返回 40301。

- POST /api/v2/chat/groups/{id}/channels 返回 200 和新频道。名称去除首尾空白，不能为空，最多 100 个 UTF-8 字节。类别最多 50 个 UTF-8 字节，空类别使用“文字频道”。类型默认 text，支持 text、announcement、voice 和 video。私密标志默认 false。
- PATCH /api/v2/chat/channels/{channel_id} 返回 200 和编辑后的频道。只更新提供的 name、category、is_private。类型和位置不通过此接口修改。空对象读取现有频道。
- DELETE /api/v2/chat/channels/{channel_id} 返回 200，data 为 null。使用软删除，保留消息和相关记录。再次请求返回 40301。

创建和编辑接收 JSON 对象，请求体上限为 1 MiB。字段不合法返回 40001。三条响应均使用 private, no-store。

频道管理与默认频道初始化使用同一群记录锁。管理事务锁定当前成员记录并重新检查角色，编辑和删除重新检查频道状态。创建位置取本群历史最大位置加 10。创建和编辑读取目标频道的当前视图后才提交。写入、回读或提交失败不返回成功。真实 Oracle 事务与客户端组合待验收。

Nuxt Web 与 Flutter 的频道管理表单支持名称、分类及私密设置，并按 UTF-8 字节提示长度限制。编辑时清空分类会发送空字符串，恢复后端默认分类。创建回执需包含当前群组 ID 和有效新频道 ID，编辑回执需匹配群组和频道。删除只在收到 `{code:200,message:"chat channel deleted",data:null,meta:null}` 后移除频道。账号、群组或后端切换后，旧回执不得更新新上下文。

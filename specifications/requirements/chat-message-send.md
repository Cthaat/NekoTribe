# 频道消息发送

POST /api/v2/chat/channels/{channel_id}/messages 使用有效会话和正安全整数频道 ID。要求当前成员有频道访问权限且状态为活跃。文字频道允许活跃成员发送，公告频道仅允许群主、管理员和版主发送，语音和视频频道返回 40001。无权访问或发言返回 40301。

请求体为 JSON 对象，最多 1 MiB。正文为字符串，去除首尾空白后最多 4000 个 UTF-8 字节。附件可单独发送，最多 32 个互不重复的正安全整数媒体 ID。正文和附件至少提供一项。回复必须指向同频道未删除消息。附件必须属于当前用户且处于 ready 状态，保持请求中的顺序。无效回复、附件和正文返回 40001。

Nuxt Web 和 Flutter 在添加到频道草稿前检查整批附件。超过 32 个、文件为空或单个文件超过 500 MiB 时拒绝本批并保留已有草稿。频道发送时逐个通过私密上传接口提交，已确认的 ID 可用于重试消息发送。Flutter 原生从文件路径上传，Web 逐个读取浏览器文件流，并由浏览器适配器组装当前文件的 multipart 请求。浏览器文件流上传失败时停止发送并提示重新选择该文件，保留正文和其他附件。

私密附件须为 `chat` 范围，且未绑定帖子或其他频道消息。先锁定媒体记录，再查关联，以防两个请求同时绑定同一附件。成功消息保留相对鉴权路径 `/api/v2/media/{id}/content`，下载权限随频道成员状态变化。公开的旧附件沿用原有写入规则。

在同一事务锁定并重新检查群组、频道访问及成员状态，锁定回复与附件记录，写入消息、附件链接和频道摘要。读取完整消息后提交，任一环节失败须回滚。响应为 200 和发送者视角的消息，使用 private, no-store。

提交后广播 chat_message 到频道。广播标注 viewer_neutral，不携带发送者的管理或关系状态，客户端按自身会话处理操作权限。Redis 故障不改变已提交的 HTTP 结果。Go、Rust 的频道广播依赖 Redis。真实 Oracle、Redis 及六种客户端组合待验收。

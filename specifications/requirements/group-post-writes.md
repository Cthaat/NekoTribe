# 群帖子发帖、删除、置顶和点赞

- 使用有效会话、安全正整数路径 ID 和 `Cache-Control: private, no-store`。事务先锁群组再检查可见性与帖子归属，与群组解散使用同一行锁。
- 创建需要发帖权限。`content` 必须为去除首尾空白后非空的字符串且不超过 4000 UTF-8 字节。可选 `media_urls` 为字符串数组，去掉空项后以逗号连接，总长不超过 2000 UTF-8 字节，单项不得包含逗号。
- 平台上传附件复用群组图片的受管 key 规则。发帖事务去重并按媒体 ID 升序加锁，按请求顺序写入媒体记录里的公开 URL。附件不存在或已删除时回滚并返回 400、40001 和「群组附件不存在或已删除」。替换地址后再次验证逗号和字节上限。外部及无法识别的旧地址按原值写入。
- 可选 `is_announcement` 默认为 false，须是布尔值。发布公告还须具有活跃 moderator、admin 或 owner 权限。生成帖子 ID 并在同一事务回读完整详情，提交后返回 `group post created`。
- 删除只允许作者或活跃管理者。可省略请求体，或者发送包含可选 `reason` 的 JSON 对象。原因可为空或 null，字符串最多 200 UTF-8 字节。持久化软删除并返回 `group post deleted` 和 null 数据。
- 两个客户端的群帖列表在删除确认后移除帖子。同一帖的删除、点赞和置顶操作串行处理。
- 置顶只允许活跃管理者。`is_pinned` 须是布尔值，返回 `post_id` 和最终置顶状态。
- 点赞和取消点赞只改变查看者自己的记录，重复操作幂等。返回事务内回读的 `likes_count` 和操作后的 `is_liked`。
- Nuxt Web 和 Flutter 校验回执的 `post_id`、布尔状态和非负安全整数点赞数，按回执更新列表和详情。请求期间，同一帖的点赞和置顶串行处理。仅置顶视图在确认取消置顶后移除该帖；写入返回 404 时移除对应帖子。切换会话或后端后忽略旧回执。
- 点赞、取消点赞和新增置顶在写入前及提交前检查帖子作者是否启用，以及操作者与作者任一方向的拉黑关系。失去可见性返回 404 并回滚。取消置顶和删除继续按各自的角色要求和资源归属处理。
- JSON 请求体不超过 1 MiB。参数错误返回 400，不可见、已删除或者跨群组路径返回 404，权限不足返回 422，失败写入或回读回滚并返回 500。
- 发帖提交后，从当前群组和帖子读取通知收件人。发起人须与当前帖子作者一致，且双方账号均启用。仅向启用了群通知、与作者任一方向均无拉黑关系的活跃成员保存 `group_post` 通知。通知带群组和帖子 ID，遵守个人推送偏好。个别通知或实时投递失败不影响已提交的帖子。

Nuxt Web 选择具体群组后、Flutter 在群组详情内，都可手动发布正文。入口按活跃成员状态和发帖角色开放，公告选项仅允许符合发帖权限的管理者使用。客户端在提交前校验去首尾空白后的 UTF-8 字节数，避免重复提交，发布成功后重读当前列表。两端可上传并移除草稿中的图片，在上传期间不能发布；提交仅包括仍在草稿中的图片地址，保留添加顺序。地址以逗号拼接后按 UTF-8 校验 2000 字节上限。会话、群组或 Flutter 后端变化后，旧表单、选图结果或迟到回执不再生效。移除草稿图片不删除已经上传的资产。

客户端确认发布时核对回执中的群组 ID、新帖 ID 和公告布尔值。回执中的公告状态须与本次提交一致，省略提交选项视为 false。结果无法确认时不清空草稿。

# 群聊成员列表

GET /api/v2/chat/groups/{id}/members 使用有效会话和正十进制安全整数群 ID。只有启用且未删除群组的活跃或禁言成员可访问。无权访问返回 40301。Oracle 查询同时约束查看者身份和成员范围。空成员列表返回 []。

仅返回活跃或禁言成员，按群主、管理员、版主、其他成员顺序排列，同类按加入时间及用户 ID 升序。显示名按群昵称、公开显示名、用户名回退。头像为空时返回 null，否则按部署的存储地址配置输出。返回成员角色和状态，不返回封禁理由或会话详情。

关闭在线状态展示的成员返回 hidden 和 null 的 last_seen_at。其余按未撤销会话在 90 秒内是否活跃计算在线状态，并返回最近活动时间。响应和 Oracle 查询绕过缓存。真实 Oracle 和客户端组合待验收。

Nuxt Web 在群聊显示该成员列表。Flutter 从频道工具栏打开当前群的成员列表，保留服务端排序，支持刷新、错误后重试和返回聊天。隐藏在线状态的成员不显示在线、离线或最近活动时间。切换频道、账号或后端时，Flutter 关闭旧成员列表并忽略迟到结果。浏览成员列表期间不推进聊天已读状态。

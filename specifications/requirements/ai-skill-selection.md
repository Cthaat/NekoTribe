# AI Skill 选择基础

Nuxt、Go、Rust 共用受控 Skill 目录、持久化启用配置和会话权限规则。Nuxt Web 与 Flutter 提供只读目录状态，部署人员通过维护命令管理启用配置。调用方必须先验证身份，每次选择都由当前后端检查会话和目标权限。

共享 Oracle 表 `N_AI_SKILL_CONFIG` 使用单行标记记录正整数 `generation` 和最长 512 字节的启用 ID JSON 数组。迁移只建空表。Nuxt、Go、Rust 内部选择读取最新配置和代数，缺行、结构不兼容、内容损坏或数据库异常时失败关闭。三端在同一连接检查共享迁移目录。代数作为配置快照标识，执行前后仍须重新授权和复核版本。

Nuxt、Go、Rust 都提供本机或容器内的维护命令。默认 `--plan` 离线校验已知 ID，`--status` 只读显示代数和启用列表，`--publish` 在独立连接上按预期代数写入。首次发布要求 0；重复初始化或后续代数过期返回 `SKILL_CONFIG_CONFLICT`。成功发布按字母顺序保存启用 ID，代数递增；空列表停用全部技能。编排服务随正常业务读取跨实例生效的配置。发生不确定提交或连接关闭失败时先查询实际状态，禁止自动重放。共享写入 SQL 见 `ai-skill-config-write.json`，命令见 `docs/ai-skill-maintenance.md`。真实 Oracle 并发和容器内执行留待统一验收。

知识问答、写作、群运营和审核生成共用事务守卫。三端在同一连接使用 `SELECT ... FOR UPDATE NOWAIT` 获取当前代数及启用列表，锁争用或读取失败时失败关闭。推理期间不持有锁或数据库连接。准备保存时重新授权，锁住配置并核对所选技能及其代数，锁随事务提交或回滚释放。配置需要显式迁移和发布。推理后保存时若配置代数变化，事务回滚并返回 409 的安全会话冲突响应。配置缺失、损坏或技能停用时返回 503，不暴露数据库或配置详情。真实 Oracle 锁争用、取消和跨实例行为留待统一验收。

独立公开知识索引工具包附带同一个 Node 维护命令及预编译运行时。离线计划无需 Oracle。连接模式单独提供可访问共享 Skill 表的 Oracle 配置，可在仅安装预编译业务后端的主机执行，业务服务、Redis、Qdrant 和模型均无需运行。

Go、Rust 的源码启动器及声明支持该能力的原生交付包可经 `start-native.mjs` 运行 `skills` 子命令。环境文件加载规则与本地启动一致。离线计划无需 HTTP 或数据库配置，连接模式由后端维护命令校验 Oracle。未声明能力的交付包不经启动器转发该子命令。

初期内置四个不可由普通输入修改的能力定义，版本均为 1：`knowledge-answer` 用于知识问答、`writing-draft` 用于写作、`group-brief` 用于群运营草稿、`moderation-advice` 用于审核辅助。它们分别对应 `knowledge`、`writing`、`group`、`moderation` 会话用途。定义可声明未来允许注册的工具，但工具未实现或未授权时不可执行；模型提出调用不等于调用成功。群草稿和审核建议不自动执行发布或处置。

受控的服务端配置显式列出启用 ID，空列表表示全部关闭；未知 ID、重复 ID、无效配置整体拒绝，不从用户消息或帖子载入配置。每次选择需在当次后端会话权限检查通过后，检查所选技能已启用且用途一致。群用途需要有效目标群 ID，其他用途禁止群 ID。技能未知、禁用、用途不一致或授权失败统一拒绝，不返回内部配置或密钥。

显式选择使用请求中的固定 ID；自动选择仅按已授权用途选择唯一对应内置技能，不解析用户文本或由模型猜测权限。返回不可共享的选择快照，至少包括 ID、版本、用途、目标群 ID、选择方式与允许的工具名，供后续持久化和审计。调用方每次请求重新授权，不能把快照当作长期授权。停用、权限撤销、模型能力、工具执行、会话存储及跨实例一致性仍需在接线时再次校验。

共同组件场景见 `ai-skill-selection-vectors.json`。它们使用受控授权替身验证选择逻辑；真实群组权限、审核权限和跨后端行为留待统一验收。

## 用户可见的功能状态

`GET /api/v2/ai/availability` 仅允许已登录用户访问。`data.knowledge`、`data.writing`、`data.group`、`data.moderation` 分别表示问答、写作、群运营及审核技能开关。`data.inference` 包含相同的四个布尔值。对应技能开启、有效模型配置可选且凭据通过传输格式检查时返回 `true`。群运营使用模型配置中的 `agent` 绑定。状态读取复用模型热切换配置，不探测模型服务。响应包含 `Cache-Control: private, no-store`。技能配置不可读返回 503，未认证返回 401。生成依然独立检查身份、目标权限、技能和模型。

`data.skills` 按知识问答、写作、群运营、审核的顺序列出四个已登记 Skill，每个用途恰好一项，含 `id`、`purpose`、正安全整数 `version` 与 `enabled`。启用状态来自同一次配置读取，与顶层用途开关必须一致。目录用于显示，不包含模型信息、凭据、提示词、工具定义、权限或目标群组。旧后端可省略此字段。Nuxt Web 与 Flutter 显示当前入口对应的技能名称、版本和状态。目录格式不符时按状态读取失败处理。账号、目标或端点变化时丢弃过期目录和响应。

Nuxt Web 与 Flutter 的问答、写作、群运营和审核助手在打开或刷新时读取状态，区分读取中、已启用、技能未启用、模型配置不可用和读取失败。旧后端省略 `inference` 时按技能状态处理，省略群运营或审核字段时保留旧入口的行为。客户端严格校验所有已定义的布尔值。配置不可用或读取失败时暂停生成，保留草稿、历史与已授权的历史操作。账号、目标或端点切换后不采用旧请求的状态。刷新只读取状态和历史。

客户端响应解码共用 `ai-availability-client-vectors.json`，覆盖旧响应兼容和新增字段验证。真实三后端、鉴权和模型留待统一验收。

目录项可包含布尔字段 `explicit_selection`。为 `true` 时，该用途的生成接口支持显式提交当前 Skill ID。当前三个后端为四个用途发布该能力。审核、写作和问答按该字段提供手动选择，旧响应省略此字段时沿用默认选择。群运营的现有显式选择保持可用。

写作生成 `POST /api/v2/ai/conversations/{id}/generate` 支持空请求体、空对象或包含 `"skill_id":"writing-draft"` 和可选 `expected_sequence` 的对象。省略 Skill 时按用途选择默认 Skill。正文限制为 4096 字节，错误 ID、其他字段、重复字段及格式错误返回 400。服务端持续校验会话归属、用途和技能启用状态。预期序号与当前最后一条用户消息不匹配时返回 409。

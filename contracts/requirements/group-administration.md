# 群通知偏好及审计日志

- 所有端点要求有效会话和正安全整数群组 ID，返回 `Cache-Control: private, no-store`，绕过 Nuxt 的两层缓存。群组不存在、已解散或停用返回 404。
- `GET/PUT /api/v2/groups/{id}/notification-preference` 只允许当前活跃成员操作自己的记录，其他身份返回 422。没有偏好时 GET 返回启用，时间戳为响应时刻。
- PUT 保留现有开关兼容。布尔 true、数字 1 或大小写不限的字符串 `1`、`true`、`yes` 启用，其他取值及缺省字段关闭。请求必须是最多 1 MiB 的 JSON 对象。
- PUT 先锁群组行，再检查成员资格，在同一事务 upsert 并回读数据库结果后提交。写入或回读失败回滚，返回 500。
- `GET /api/v2/groups/{id}/audit-logs` 仅允许本群的活跃 owner、admin、moderator，授权与计数和分页在同一 SQL 中完成。时间相同按序列 ID 降序，空页保留原始总数。
- 审计响应保留原字段，并返回 `actor_id` 和可空的 `target_user_id`。不可读的公开用户资料返回 null，历史日志仍返回。详情为可解析 JSON 时返回解析结果，旧文本按原值返回。
- Nuxt Web 和 Flutter 的群管理向当前活跃 owner、admin 和 moderator 提供只读审计日志。两个客户端按服务端顺序分页，提供空页、失败重试及上一页和下一页。在记录中展示操作、时间、操作者和目标 ID，历史资料缺失时仍能核对 ID。详情按纯文本呈现，界面省略 IP 字段。
- 账号变更、关闭日志面板或 Flutter 切换后端时取消在途读取。身份变更立即清除已经显示的日志，重新进入群管理后才能加载新身份的记录。每次读取由后端重新校验权限。

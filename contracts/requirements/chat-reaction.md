# 频道消息反应

POST 和 DELETE /api/v2/chat/messages/{message_id}/reactions 分别添加和撤销当前用户的反应。两者要求有效会话、正安全整数消息 ID、可访问的未删除消息及 JSON 对象。emoji 为去除首尾空白后的非空字符串，最多 16 个 UTF-16 代码单元和 32 个 UTF-8 字节。无效输入返回 40001，无法访问频道返回 40301，目标消息不存在或已删除返回 40401。

活跃和禁言成员可对可见频道的消息添加和撤销反应。私密频道仅限管理角色。反应由消息、用户和 emoji 唯一标识。重复添加或撤销不存在的反应均成功，不能修改其他用户的反应。

按群组、成员和目标消息顺序加锁并复核权限。写入和响应消息回读使用同一事务，提交后广播 chat_reaction_updated。HTTP 返回当前操作者视角的完整消息，使用 private, no-store。广播带 viewer_neutral，反应计数可共用，当前用户的反应标记由 HTTP 响应或已有本地状态维护。真实 Oracle、Redis 与客户端组合待验收。

两个客户端对同一条消息一次只提交一个反应操作。回执的群组、频道和消息须对应当前请求，反应计数必须为正整数，目标反应须确认添加或撤销状态。反应回执与广播只更新已有消息的反应列表，保留正文、置顶与权限。切换账号、频道或 Flutter 后端后忽略旧请求，已删除的消息不会因反应回执重新显示。

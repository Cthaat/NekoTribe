# 群聊首页群组列表

`GET /api/v2/chat/groups` 要求有效 access token 和活跃会话。只列出当前用户以活跃或禁言状态加入的启用群组。使用共享分页规则，按成员数、群创建时间和群 ID 降序。空页返回数组。

频道数和未读数只统计当前角色可见的未删除频道。未读数只统计超过当前用户已读位置的未删除消息。群主、管理员和版主可见私密频道。返回该用户的成员身份、角色、状态、加入时间和管理权限。

当前页和总数从同一条数据库查询读取，共用同一份成员筛选数据。越界页仍返回筛选后的实际总数。频道数和未读数仅为当前页群组计算。

Nuxt Web 和 Flutter 在群聊入口每页请求 20 个群组。点击加载更多时校验服务端页码，按群 ID 合并到当前列表，保留原有顺序和正在查看的频道。翻页失败保留已有列表并允许重试。刷新从第一页重新加载，账号或 Flutter 后端切换后忽略旧分页响应。

本接口只读。空群的默认频道由频道列表初始化。响应及查询不使用缓存。真实 Oracle 与两客户端切换仍待验收。

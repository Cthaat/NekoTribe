# 删除帖子评论共同需求

`DELETE /api/v2/comments/{id}` 要求有效会话和规范安全正整数评论 ID，响应为 `private, no-store`，内部错误脱敏。评论必须未删除，所属帖子必须未删除且当前用户可见；不存在、已删除或不可见均返回 404 `评论不存在`。可见的其他用户评论返回 422 `只能删除自己的评论`。

仅评论作者可软删除评论。更新语句本身必须同时绑定评论 ID 和当前用户，检查作者、评论未删除、帖子未删除及 `fn_can_view_post`；更新零行返回 404 `评论不存在`，避免权限或评论状态在检查之后变化时仍删除。成功返回 `comment deleted` 和 null data；重复删除为 404。删除不会主动删除回复、点赞或通知，其数据库触发器及其他既有副作用以共享数据库为准。

这些条件保证语句执行时的检查，不保证数据库语句快照和提交之间的并发变化。Oracle 触发器、并发删除/权限变化、共享数据以及两个客户端仍需隔离环境真实验收。此规则相对旧接口收紧了无权查看帖子时的删除权限和路径 ID 解析。

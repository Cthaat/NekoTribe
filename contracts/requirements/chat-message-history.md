# 频道消息历史

GET /api/v2/chat/channels/{channel_id}/messages 使用有效会话和正十进制安全整数频道 ID。启用且未删除的群组仅向活跃或禁言成员开放，私密频道仅向群主、管理员和版主开放。频道不存在或不可访问时返回 40301。响应和 Oracle 查询绕过缓存。

分页窗口按创建时间、消息 ID 降序选取，页内按两者升序返回。q 去除首尾空白并转小写，按原有 SQL LIKE 规则查找消息正文。总数与列表使用同一频道、未删除消息、公开作者记录及搜索条件。空列表和空附件、反应均返回数组。

每条消息返回公开作者、当前查看者权限、回复摘要、附件及反应。仅当被回复消息仍在同一频道且未删除时返回摘要。附件按位置及关联 ID 排序，反应按数量降序再按 emoji 升序，包含 reacted_by_me。只有管理角色可以置顶，作者或管理角色可删除。

使用与频道状态更新一致的群组和成员锁，并在加锁后复核权限。不带有效搜索词的第一页非空时，在映射附件和反应后使用该页最后一条消息的 ID 推进已读游标。旧游标请求不会回退。搜索、后续页和空结果不写入已读。失败应回滚。真实 Oracle 并发和两客户端联调仍待验收。

Nuxt Web 和 Flutter 都能在当前频道搜索消息。Flutter 搜索时按原关键词翻页，保留正在编辑的消息草稿，退出搜索恢复完整频道。两端的实时删除会移除命中结果，未筛选的实时新消息不混入搜索列表。重连会重新读取搜索结果。账号、频道或后端变更时废弃旧请求。

两端检查分页元数据及消息数组。页码和每页条数须与请求一致，消息须属于请求频道，群组与消息 ID 为正安全整数，页内消息 ID 唯一且未删除。异常页不显示、不推进客户端已读。Nuxt Web 切换频道或搜索词时清除旧列表，读取失败显示重试入口，补读失败保留已有消息并重试同一页。

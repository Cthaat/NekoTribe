# 用户审核处置

`POST /api/v2/moderation/users/{user_id}/actions` 要求有效会话和现有审核权限，响应禁用共享缓存。支持 `ban`、`unban`、`mute`、`unmute` 和 `note`。目标 ID 必须为正安全整数的十进制表示，目标不存在返回 404，处置本人返回 403。

- 封禁和解封只处理正常账号或有封禁历史的已暂停账号。待激活、禁用或无封禁记录的暂停账号返回 409，防止解封意外激活其他状态。封禁在同一事务中设置账号暂停、撤销该账号的活跃会话、替换同类型限制并记录审计。解封恢复受审核暂停的账号并撤销封禁限制，旧会话保持撤销状态。
- 显式时长接受整数或十进制数字字符串，上限 87600 小时。封禁省略时保留 24 小时的记录默认值，0 表示无限期。禁言必须为正时长，省略时读取 `default_mute_hours`，缺失或无效设置回落到 24，配置为 0 时最少 1 小时。解封、撤销禁言与仅备注无需时长。
- `mute` 替换已有活跃禁言限制，`unmute` 撤销对应限制，`note` 仅记录审计。备注和原因去除首尾空白，分别最多 1000、200 个 UTF-8 字节。目标行加锁后执行建案、处置、审计与按目标读回。任一失败都回滚。
- Nuxt Web 和 Flutter 省略默认时长，让服务端统一决定。Flutter 也支持显式输入，非法文本无法作为默认值提交。
- [定时封禁](./moderation-ban-expiry.md)到期后由登录和原生后台扫描恢复账号。[内容发布限制](./moderation-publish-policy.md)覆盖普通发布、群组与聊天。Oracle 真实并发、时间语义与部署组合仍待验收。

# AI 生成流

写作、知识问答、群运营和审核建议共用同一流协议。客户端在既有四个会话生成请求发送 `Accept: text/event-stream` 启用。默认 JSON 请求与响应仍按各自规范执行。

流以 UTF-8 SSE 返回，禁止缓存。每个事件只有一个 JSON `data:` 负载。

| 事件 | 负载 | 行为 |
| --- | --- | --- |
| `delta` | `{"text":"增量文本"}` | 提示用户请求仍在生成。只发送面向用户的最终推理文本，不发送工具调用或提供方内部推理内容 |
| `done` | 原有 JSON 成功信封 | 对需要保存的会话，仅在既有权限、顺序及来源核对和数据库提交成功后发送。无足够来源的正常结果可以没有增量 |
| `failed` | 原有公共 V2 错误信封 | 流已开始但生成未能正常完成。客户端显示错误并通过正常 API 核对历史 |

流开始前收到的业务错误保持原 HTTP 状态和公开错误载荷。`done`、`failed` 是终止事件，收到其一后关闭连接。流无终止事件即断开时，客户端显示生成中断并重新读取历史。用户点击停止时取消请求，服务端取消等待和提供方请求。推理中止或保存前失败不得写入助手消息。若网络断开时提交已经完成，历史 API 是最终依据。

## 推理提供方

最终生成启用 `stream: true`。OpenAI-compatible 读取 SSE `choices[0].delta.content` 并校验完成原因与 `[DONE]`。Ollama 读取 NDJSON `message.content` 直到 `done: true`。每行及每 SSE 事件上限 64 KiB，整体 1 MiB。沿用提供方超时和取消信号。累计文本继续执行现有结构化验证、权限与持久化顺序。群运营工具提案继续使用已有只读工具流程。

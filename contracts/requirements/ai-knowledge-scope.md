# 知识问答范围

创建 `purpose=knowledge` 的会话可以选择 `knowledge_scope`。省略时为 `public`，既有会话通过显式 Oracle 迁移使用同一默认值。创建后范围不可修改。创建、详情和列表中的问答会话返回其范围，列表可按范围筛选。

| 范围 | group_id | 允许的来源 |
| --- | --- | --- |
| public | 空 | 现有公开帖子、评论、群公开内容和平台规则 |
| personal | 空 | 本人未删除且当前可见的帖子，以及本人当前可见的收藏贴 |
| group | 已加入群 ID | 指定群的未删除帖子及评论，含置顶/公告。现有作者状态和屏蔽关系同样生效 |

其它会话用途沿用既有参数与权限规则。群管理员 Agent 的用途 `group` 继续要求管理权限。问答会话的群范围仅要求当前活跃成员，退群、被踢或群停用后详情、历史、追加、生成及删除均拒绝，列表跳过该会话。

群检索先核对当前有效成员，再按准确群 ID 读取独立的群向量池。索引服务使用独立群配置及集合，每个点记录 `scope=group` 和 `group_id`。公开索引及接口沿用公开来源。群检索接口 `POST /internal/v1/knowledge/group-search` 仅接受内部服务令牌，输入 `{query,limit,group_id}`，响应回显群 ID 并只返回此群候选。群索引不可用时可使用同范围的 Oracle 查询。

服务端使用当前 Oracle 数据复核每个候选的群归属、访问权限和来源版本。在推理后再次复核依赖内容。保存事务中先核对会话序号、所属账号和范围，再核对成员与来源。历史恢复时再次校验依赖，防止已不可见的内容继续通过历史引用展示。个人范围只读取绑定账号的数据，不能按查询串共享结果。群与个人范围在生成结束前只传输公开状态信息，正文在权限、来源和事务核对完成后通过保存回执交付。

公开答案沿用版本 1。受限范围的助手消息使用 `{version:2,answer,sources,dependencies}`。两份来源列表均使用现有的 `{kind,id,version}`，最多 20 项。 `sources` 是展示给用户的引用，`dependencies` 覆盖所有本次证据与使用的历史依赖，包含 `sources`。任何依赖失效都会隐藏受影响历史回答。

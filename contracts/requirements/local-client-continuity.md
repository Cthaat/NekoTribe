# 桌面通知和本地草稿

Web 用户可以在账号偏好中为当前浏览器开启桌面通知。只有这一显式操作会触发浏览器授权。通知来自现有已认证的 `notification_created` 事件，遵循站内推送开关和类型偏好。在有授权且页面处于后台时显示通用提醒，点击可返回当前账号的站内通知页。已有通知正文保留在站内。账号切换后关闭旧提醒；关闭站点或浏览器不支持时仍可使用站内通知。[Notifications API](https://notifications.spec.whatwg.org/)

Flutter 为当前账号和配置后端保留设备上的未发布草稿。普通发帖编辑器与各群发帖编辑器使用独立草稿，恢复文本和 Markdown 编辑状态。草稿保存在本设备，可显式丢弃；确认发布成功后清理。AI 填入和云草稿继续使用对应的编辑流程，恢复本地草稿无需联网。设备草稿只缓存可离线恢复的文字和编辑模式。Flutter 发布说明随附 Windows 和 Android 构建预检及机器的实际检查结果。

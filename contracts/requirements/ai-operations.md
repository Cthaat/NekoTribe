# AI 运维与评测

`GET /api/v2/moderation/ai/operations` 使用现有平台审核权限。返回私有、不可缓存的 V2 成功信封。返回当前后端、模型配置修订、四个用途及绑定提供方的状态、Redis 服务级窗口用量、知识索引、审核反馈和 Skill 目录。不提供写操作。

- **模型**字段只包含用途、配置中的提供方 ID、模型配置 ID、版本和健康状态。读取提供方的模型列表确认配置模型存在。缺配置、缺凭据、提供方不可达和模型不在列表分别显示。绝不返回提供方 URL、认证头或环境变量名。
- **配额**读取现有服务级 Redis 计数，不消费额度。键不存在时为 0，读取失败时为 null，窗口与模型配额一致。
- **索引**由授权的内部检索服务返回，使用既有服务令牌和就绪入口。查询参数 `detail=1` 增加集合点数和同步文件中的阶段、上次成功时间、下次计划时间，时间为 Unix 毫秒。无同步记录时相应字段为 null。
- **审核反馈**按 `model_id`、`model_version` 和 `config_revision` 汇总最新 100 个分组。显示 helpful、incorrect、insufficient 分布，准确率为 helpful ÷ (helpful + incorrect)。只有 insufficient 或无有效评分时返回 null。准确率是审核员反馈口径。
- **Skill**仅显示已有目录、启用状态及配置代数。现有维护工具继续负责配置写入及审计。

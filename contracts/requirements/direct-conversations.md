# 私信会话列表与创建

`GET /api/v2/chat/direct-conversations` 返回当前登录用户参与的未删除会话。列表按可见的最后消息时间（没有时用会话更新时间）降序排列，同时间按会话 ID 降序。使用共享分页规则，返回参与者公开资料、最后一条消息摘要和未读数。未读数只统计超过该用户已读位置的未删除来信。空列表返回数组。

总数与当前页从同一条数据库查询读取，共用会话范围和参与者公开资料过滤。越界页返回空数组，仍保留可列出的会话总数。

可选 `conversation_id` 只筛选指定会话，用于从私信通知打开已有会话。仅接受单个规范正十进制安全整数，空值、重复或非法值返回 400 `conversation_id 参数错误`。参与者、软删除与资料可用性过滤照常生效。无可见匹配时返回空数组、total 为 0。筛选为只读，使用同一响应与分页结构。

Nuxt Web 与 Flutter 每页请求 20 条会话，提供上一页和下一页。翻页只改变会话列表，保留当前打开的聊天。实时变化重新读取当前请求页，删除事件在回读前立即隐藏匹配的旧预览。后续页为空时回读第一页。翻页失败保留已有页面，账号或 Flutter 后端切换时清空分页并忽略旧响应。

客户端校验整个列表回执。页码与每页条数须匹配请求，元数据要包含有效总数和布尔型 `has_next`。会话 ID 与参与者 ID 均须为正安全整数，页内会话 ID 不得重复，未读数须为非负安全整数。按会话 ID 筛选时，返回项必须与请求 ID 一致。异常页按读取失败处理。只有通过校验的空页才可触发回读第一页。

`POST /api/v2/chat/direct-conversations` 通过 `target_user_id` 接受正十进制安全整数的目标用户 ID，拒绝自己、停用或不存在的目标，并复用私信发送的拉黑和陌生人规则。按双方用户 ID 的大小构造唯一会话键。重复或并发创建须返回同一个有效会话。若唯一键已被软删除会话占用，返回 40901，避免恢复旧历史。成功消息为 `direct conversation ready`。客户端核对返回会话 ID 以及参与者的用户 ID。切换会话或账号时清除旧消息和草稿，忽略先前上下文中的打开响应，Flutter 切换后端时同样处理。

两个接口均要求有效 access token 与活跃会话，并返回 `Cache-Control: private, no-store`。服务端须绕过响应及查询缓存。真实 Oracle 并发和两客户端切换后端仍待验收。

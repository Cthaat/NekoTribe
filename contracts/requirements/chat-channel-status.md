# 频道已读和静音

使用有效会话和正十进制安全整数频道 ID。仅启用且未删除群组中的活跃或禁言成员可写入自己的频道状态。私密频道仅允许群主、管理员和版主。无法访问或频道不存在返回 40301。所有响应使用 private, no-store。

- PUT /api/v2/chat/channels/{channel_id}/read-status 接收可选 JSON 对象。省略或传 null 表示读到当前频道最新未删除消息。指定的 last_read_message_id 必须为正安全整数，且消息属于本频道并未删除。否则返回 40001。已读游标只能前进。响应返回实际保存的 last_read_message_id 和按该游标计算的 unread_count。
- PUT /api/v2/chat/channels/{channel_id}/mute-status 接收 JSON 对象。按统一布尔转换设置 is_muted。重复静音或取消静音是幂等操作。响应返回 channel_id 和 is_muted。
- 请求体上限为 1 MiB。锁定群记录后重新检查并锁定成员记录，再写入用户状态。已读响应在提交前读取保存的游标和未读数，只有提交成功才返回成功。

Nuxt Web 和 Flutter 在前台频道成功加载最新消息页后，仅提交已加载消息中最大的消息 ID，空页不提交。浏览更早分页或 Web 搜索结果时不推进已读位置。Web 使用和本次频道与游标匹配的服务端回执刷新未读角标，忽略会话或频道切换前开始的回执。写入失败后保留已加载消息，等待下一次刷新重试。回到前台或实时连接恢复时重新读取活跃频道。

两端对同一频道只允许一个静音写入请求在途，校验回执的频道 ID 和布尔状态后才更新界面。会话或 Flutter 后端切换后忽略旧回执。Web 防止较早开始的频道列表请求盖掉已确认的静音结果；Flutter 重新打开频道列表时先等该群仍在途的写入结束。静音时隐藏未读角标，未读数和已读位置独立保存。

当前频道可见且未按关键词搜索时，两端合并短时间内收到并显示的新来信，通过已读接口提交该批次范围内已显示的最大消息 ID。重复事件和本人消息不触发新的已读写入。切换账号、频道、Flutter 后端或开始搜索时清除待提交批次。后台或搜索时的事件不触发已读写入。

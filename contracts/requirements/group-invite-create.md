# 创建群组邀请

POST /api/v2/groups/{id}/invites 仅允许启用且未删除群组的活跃成员调用。要求有效会话、正十进制安全整数群组 ID 和 JSON 对象。响应为 private, no-store。

invitee_id 省略或为 null 时创建链接邀请，使用 32 位大写十六进制随机码。提供时必须是其他活跃账号的正安全整数 ID，并且账号在该群组没有成员记录。定向邀请的最大使用次数为 1，返回的邀请码和链接均为 null。链接最大次数默认 1，范围 1 至 99999。expire_hours 默认 168，范围 1 至 8760。次数和时长必须是整数。message 可省略或为 null，字符串最多 200 个 UTF-8 字节。

先锁定群组，再确认邀请者与接收者的资格。邀请写入和符合群组及通知类型偏好的定向通知在同一 Oracle 事务提交。全局推送偏好只控制实时投递，实时事件在提交后投递。实时投递失败时已保存的邀请仍返回成功。

成功返回 invite_id、invite_code、invite_url 和 UTC 格式的 expires_at。参数错误返回 40001，群组或接收账号不存在返回 40401，权限不足、自邀或目标已有成员记录返回 42201。真实 Oracle、Redis、定向响应及客户端链接流程待单独验收。

Nuxt Web 可从群聊发送定向邀请，Flutter 可从群管理搜索并选择接收者。两端只向明确选中的账号发送定向邀请，输入变化后清除选择，忽略旧搜索结果。Nuxt Web 搜索框有内容且未选接收者时禁用提交，清空搜索后可创建链接。发送结果无法确认时提示先查看邀请历史。定向邀请沿用独立的接收和响应流程，不提供可分享的链接。

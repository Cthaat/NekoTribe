# 群帖子与评论的访问范围

- `/api/v2/groups/{id}/posts` 及其后代使用已认证会话，路径 ID 必须是正安全整数。响应使用 `Cache-Control: private, no-store`，定向读取绕过两层 Nuxt 缓存。
- 群组须存在、活跃且对当前用户可见。帖子须属于路径群组且未删，评论须属于路径帖子且未删。对不可见群组、已删除资源或归属不匹配返回 404，不执行写入。
- 改动群内容的事务先锁定群组行，与解散和群组配置变更使用相同的锁顺序，再检查权限和资源归属。写入或提交失败时回滚。
- 创建帖子沿用群组发帖规则。创建评论要求有效成员权限，父评论须属于同一帖子且未删。删除由作者或有权限的管理者执行，置顶要求管理权限。查看者可增减自己的点赞，重复操作保持幂等，计数取持久化结果。
- 创建操作先在同一事务读取返回数据并提交，通知在提交之后尽力发送。通知查询使用归属匹配的帖子、父评论和当前可见的群组。
- Nuxt Web 和 Flutter 继续使用现有 URL、字段和成功响应。Go 与 Rust 的原生实现须使用相同约束。

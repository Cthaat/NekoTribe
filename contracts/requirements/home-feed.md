# 首页信息流

Nuxt Web 和 Flutter 首页提供推荐、关注、热门和群动态。推荐使用 `GET /api/v2/posts?timeline=recommended`，关注使用现有 `timeline=following`，热门使用现有 `/api/v2/posts/trending`。后端沿用普通帖权限、分页和 DTO。无筛选关键词时，推荐采用下列顺序。

1. 继续应用推荐反馈。`not_interested` 隐藏目标帖子，`show_less` 降低同一作者的排序。反馈表未就绪时，仍可使用关注、标签与发布时间排序。
2. 已关注作者加 45 分。与本人近 30 天点赞或收藏的另一条当前可见帖存在相同标签，加 30 分。发布时间在最近 6 小时、1 天、3 天或 7 天分别加 30、20、10 或 5 分，只取最高档。
3. 同分按发布时间及帖子 ID 降序。匿名推荐按发布时间及 ID 降序。使用关键词时保留现有搜索行为。只有显式请求推荐流时才启用新排序。

群动态通过 `GET /api/v2/feed/groups` 分页读取。接口要求登录，只列出当前仍为有效成员的群内可见帖子，按发布时间及帖子 ID 降序。群或作者停用、群或帖子删除、发帖人与当前账号存在任一方向屏蔽时，内容不显示。返回既有群帖字段及 `group_name`，包括现有投票和 Markdown 正文。无匹配内容时返回空页。客户端以正常卡片呈现帖子和所属群，点击可以打开原帖。推荐、关注和群动态从当前账号实时查询，禁用共享响应缓存。

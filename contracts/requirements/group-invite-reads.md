# 群组邀请列表和邀请码预览

GET /api/v2/groups/{id}/invites 要求有效会话和正十进制安全整数 ID。仅状态为 active 的群主、管理员及版主可查看启用且未删除的群组邀请。群组不可用返回 40401，管理权限不足返回 42201。列表包含链接及定向邀请，保留历史状态。status 支持单值 pending、accepted、rejected 或 expired，筛选以已存储的状态为准。分页以 created_at 倒序、invite_id 倒序排列；超出末页返回空数组和完整分页元数据。

GET /api/v2/groups/invite-codes/{code} 要求有效会话。去除首尾空白后校验 1 至 32 位 ASCII 字母数字，并转大写。不存在或只属于另一账号的邀请码返回 40401。过期、用尽、非 pending、重复匹配或所属群组已停用的码返回 42201。有效时返回完整群组资料、邀请者、可空消息和 is_valid=true。预览只读，邀请码仍由入群事务消耗。

两条接口均返回 private, no-store。Nuxt 的两层缓存绕过这些请求。服务端请求日志隐去邀请码路径段。真实 Oracle 与客户端联调待验收。

Nuxt Web 和 Flutter 的群管理可分页查看链接及定向邀请，显示状态、邀请者、用量和有效期。定向邀请显示受邀者，复制动作仅用于服务端返回仍有效的链接邀请。加载失败时可重试当前页。关闭列表、切换账号或 Flutter 切换后端时取消在途读取并丢弃旧页。

# 当前用户加入或退出群组

POST /api/v2/groups/{id}/members/current 与 DELETE /api/v2/groups/{id}/members/current 要求有效会话及正十进制安全整数群组 ID，只操作当前用户。响应为 private, no-store。POST 接受空请求体或 JSON 对象，invite_code 可省略或为 null，字符串去除首尾空白并转大写，上限为 32 个 UTF-8 字节。

加入要求群组启用且未软删除。已有任意成员记录返回 42201，且不会消耗邀请码。无邀请时，公开且不需审批的群组直接加入，其他可申请群组返回 pending，秘密群组返回 42201。邀请码必须属于目标群组、未过期、可用且适用于当前用户，有效时直接加入并登记邀请人。最后一次使用将邀请改为已接受。成功返回 member_id、group_id、user_id、role、status。

退出或取消申请删除当前用户的成员记录。群主必须先转让群组，被封禁的成员不能通过退出删除封禁记录，两种情形返回 42201。无成员记录返回 40401。成功响应 data 为 null。

先锁群组，再读取并锁定成员记录。消耗邀请码和插入成员处于同一事务，条件更新重新验证邀请码资格。写入失败回滚，成员计数由现有 Oracle 触发器维护。真实 Oracle 与客户端联调待验收。

Flutter 群组详情按成员状态显示加入、取消待审批申请或退出，操作成功后重读群组详情。非公开群组仅在成员状态为 active 时请求动态；发布入口还须符合群组发帖角色限制。切换会话或后端时丢弃旧详情和旧操作回执；从详情返回列表时按原筛选重新读取。

Nuxt Web 群组卡片和详情也区分申请加入、取消待审批申请和退出。禁言成员仍可退出，群主和被封禁成员不能通过此入口退出，秘密群组的非成员须走邀请。加入或退出后，Nuxt 重读当前筛选的列表及打开的群组详情，不根据回执推算成员人数。详情仅在当前用户有权时请求成员与动态。

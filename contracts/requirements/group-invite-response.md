# 定向邀请收件箱和响应

GET /api/v2/users/me/group-invites 仅列出当前账号收到的仍有效的定向邀请。筛选待响应、未过期、未用尽以及启用且未解散的群组。按创建时间倒序及邀请 ID 倒序排列。空页保留总数。

可选 `invite_id` 按单条邀请筛选，必须是规范十进制正安全整数。空值、重复值、前导零、非整数或超出安全整数范围时返回 HTTP 400／40001「invite_id 参数错误」。在分页、总数计算前应用筛选，沿用当前账号和有效性条件。查不到、属于其他账号或已失效时返回成功空列表及总数 0。省略筛选时继续读取完整收件箱。

POST /api/v2/groups/invites/{invite_id}/responses 要求正十进制安全整数邀请 ID 和 JSON 对象。标准字段 accept 为布尔值，旧客户端可单独发送 action=accept、decline 或 reject。两个字段同时提供、缺失或格式错误时返回 40001。

只有邀请接收账号可以响应。找不到账号名下的邀请时返回 40401。公开链接通过邀请码入群。已处理、过期、用尽或群组不可用返回 42201。接受时，已有任何成员记录也返回 42201。拒绝无需写入成员，可清理已通过其他方式加入的群组留下的邀请。

先定位当前账号名下的邀请，再锁群组并锁定邀请。只更新尚可响应的邀请。接受时更新邀请、增加使用次数并插入活跃普通成员，共同提交，失败回滚。拒绝只更新邀请状态与响应时间。成功返回 invite_id、group_id、status。两条接口要求有效会话，均使用 private, no-store。

真实 Oracle 并发与客户端组合待验收。

通知入口在 Nuxt Web 和 Flutter 都打开邀请收件箱。优先取通知的 `metadata.invite_id`，旧通知可用 `group_invite` 资源 ID。两者冲突或均无有效 ID 时打开完整收件箱。目标明确时按 ID 读取，仅显示匹配邀请。邀请失效时提示不可用并提供完整收件箱入口。两端按分页读取和去重，接受或拒绝时锁定当前操作，只有回执的邀请 ID、群组 ID 及状态均匹配时显示成功。完成或无法确认结果后重新读取第一页，不自动重发响应。账号变化及 Flutter 切换后端时清除收件箱并忽略旧请求。

确认接受后，Nuxt Web 提供打开该群动态的入口，Flutter 提供打开该群详情的入口，并重新读取已缓存的「我的群组」页。拒绝或回执不匹配时不提供加入成功入口。

# 普通帖与群帖的 Markdown 长文

普通帖和群帖编辑器可切换到 Markdown 长文。长文使用 UTF-8，正文为非空字符串，最多 16,384 字节。发帖时提交原有 `content` 字段及可选 `markdown` 字段。两个客户端由长文正文生成普通文本摘要，原有帖子字段继续可读。普通帖的引用、回复和转发仍用原有编辑器。群帖仍沿用当前发帖和公告权限。

新建长文时，帖子、长文及其他附件在同一事务提交。普通帖编辑可以通过 `markdown` 字符串替换长文，传 `null` 移除长文，省略该字段保留已存长文。普通帖、群帖、主页置顶的返回体可包含 `markdown`，沿用原帖读权限。草稿和定时发布保留长文，继续使用正常的发帖权限及原子事务。

Nuxt Web 和 Flutter 在帖子和详情中渲染段落、标题、强调、引用、列表、表格及代码块。支持常用代码语言高亮，未知语言仍可读。用户原始 HTML 只作为文字处理。渲染限制在预定义的结构和属性内，链接只接受带主机的 HTTP/HTTPS 地址。Markdown 中的图片只显示替代文字，上传图片继续走原有附件入口。浏览器不会执行 Markdown 中的脚本、样式和嵌入组件。[markdown-it 安全说明](https://github.com/markdown-it/markdown-it/blob/master/docs/safety.md) · [Dart Markdown 解析器](https://pub.dev/packages/markdown)

Oracle 在 `N_POST_MARKDOWN` 保存长文，普通帖或群帖只能关联其中一个源，且同一帖只能关联一份正文。三后端检查只读结构；显式长文写入在结构未就绪时返回 503。未应用长文表的旧环境仍可读取普通帖子。

# 审核仪表盘统计与设置

`GET /api/v2/moderation/stats`、`GET /api/v2/moderation/settings` 和 `PATCH /api/v2/moderation/settings` 需要有效会话和现有审核权限。三后端直接查询同一个 Oracle 数据源，响应为标准 V2 JSON，并设置 `Cache-Control: private, no-store`。

- 统计包含待审、通过、驳回和标记案件数。今日处理数按 Oracle 服务器日期起点和既有处置动作计算，平均处理分钟只计算已结束案件。未关闭举报包括 `pending` 和 `in_review`。申诉成功率分母为已有决定的申诉，百分比取整，无决定时为 0。
- 读取设置按键排序，值统一返回字符串并附类型、标签、描述和 UTC 更新时间。可写键取自现有四个迁移种子。`auto_hide_report_threshold` 保留原键名，用于[提高内容举报案件的优先级](./moderation-reports.md)；设置 `0` 可关闭自动提级。
- PATCH 明确提供 `settings` 数组。空数组读取快照。未知键、重复键、错误类型或无效值使全批返回 400。布尔接受布尔类型以及字符串 `true`、`false`、`1`、`0`，存为 `true` 或 `false`。数字接受非负安全整数或十进制数字字符串，规范成十进制字符串。字符串值忽略首尾空白。
- 通过校验后按设置键顺序逐项更新，记录操作用户与时间，并在提交前读回结果。任一写入或读回失败则回滚全批。客户端只提交相对读取快照修改过的键，切换身份清除旧草稿。
- 隔离测试覆盖越权、统计分母及空结果、类型归一、输入校验、批量回滚和两端编辑流程。真实 Oracle 日期边界、并发与部署矩阵仍待验收。

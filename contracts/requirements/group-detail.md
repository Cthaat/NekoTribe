# 群组详情

GET /api/v2/groups/{id} 和 GET /api/v2/groups/by-slug/{slug} 共享同一份群组详情。需要有效会话，ID 须为正十进制安全整数。slug 使用解码后的原值精确匹配。参数错误返回 40001。群组不存在或软删除返回 40401。

按 Nuxt 现有详情语义返回未删除群组的资料，供查看群资料和发起入群流程使用。返回群组公开资料、标签、群主公开资料及当前查看者的成员记录。成员记录的存在、状态和角色分别返回，调用方以状态判断权限。群内帖子等子资源继续使用各自的访问规则。没有标签时返回空数组，头像或封面缺失时返回 null。群主不存在或不再有公开资料时返回 40401。

响应及 Oracle 查询绕过缓存，避免跨后端变更后返回旧成员状态。真实 Oracle、历史数据库版本和两客户端组合待验收。

Nuxt Web 的群组发现页支持通过 `/groups/discover?slug=<短名>` 打开详情弹窗。Flutter 使用已有群组短名路由。两端将短名编码为一个 API 路径段，验证详情返回同一短名以及安全的群组 ID。按 ID 查询的返回 ID 也必须与请求一致。已登录用户能脱离列表直接打开群组链接；加载失败时保留原查找目标供重试，切换账号或 Flutter 后端时丢弃旧详情。

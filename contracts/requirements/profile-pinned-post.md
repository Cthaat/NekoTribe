# 个人主页置顶帖

每个账号可在自己的主页上把一条可见帖子置顶。置顶另一条帖子会替换当前记录。取消置顶后帖子回到原来的排序位置。群内置顶沿用群内容接口。

`PUT /api/v2/users/me/pinned-post` 以 `{post_id}` 设置置顶，返回 `{post_id}`。帖子必须由当前账号发布、尚未删除，并且当前账号有权读取。未找到符合条件的帖子返回 404。`DELETE /api/v2/users/me/pinned-post` 取消置顶，返回空数据。本来没有置顶时也成功。这两个操作对当前账号行加锁，使并发替换和取消按提交顺序生效。

`GET /api/v2/users/{id}/pinned-post` 返回 `{post}`，其中 `post` 为按当前访问者权限映射的标准帖子对象。主页没有置顶帖或访问者看不到置顶帖时 `post` 为 `null`。该接口保留帖子原有可见性，不增加浏览次数。三条路径均沿用主页会话鉴权，响应禁用缓存。

Nuxt Web 和 Flutter 在主页帖子第一页先显示置顶帖并标记，同时从普通结果去掉同一条帖子的重复项。普通列表继续按原规则分页和计数。主页所有者从自己的帖子菜单设置或取消置顶。单独的主页置顶读取失败时，普通帖子列表仍可浏览。

`N_USER_PINNED_POSTS` 用 `user_id` 主键限制每人一条，并关联原帖。Nuxt 显式迁移创建结构，三个原生后端只检查结构。结构未就绪时置顶接口返回 503。

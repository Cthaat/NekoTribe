# 群聊频道列表

`GET /api/v2/chat/groups/{id}/channels` 要求有效 access token 和活跃会话。群 ID 为正十进制安全整数。群须启用且未删除，当前用户须为活跃或禁言成员。无权访问返回 40301。只有群主、管理员和版主可见私密频道，响应中的 can_manage 使用同一角色规则。

返回未删除频道，按类别、位置、创建时间和频道 ID 升序。每个频道包含当前用户静音状态、超过已读位置的未删除消息数量，以及属于当前频道且未删除的最后消息摘要。没有摘要时返回 null。空列表返回数组。

没有任何未删除频道时，锁定群记录后重新计数，以群主为创建者在同一事务内建立公告板和综合讨论。任一写入失败应回滚。另一请求已经建立频道时直接读取已有频道。响应及数据库查询绕过缓存。真实 Oracle 并发与客户端联调待验收。

Nuxt Web 和 Flutter 校验响应为数组，频道 ID 须为唯一的正安全整数，所有记录的群组 ID 必须匹配请求。合法空数组与加载失败使用不同界面状态。Nuxt Web 切换群组时清除旧频道、成员和历史，当前群组可独立重试频道列表。成员名单失败不阻断频道及消息加载。Flutter 切换会话或后端后清除仍打开的旧频道选择器，并忽略延迟的列表响应。

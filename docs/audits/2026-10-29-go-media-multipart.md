# Go 媒体 multipart 暂存检查点

Go 新增尚未接线的流式 multipart 解析组件：每个请求创建独立的临时目录，按 `file` 优先、`media` 次之选择首个文件，保留首个 alt_text/description，限制单文件、所有文件数据、字段总量及字段/文件数量。错误时只删除本请求创建的文件和空目录；超出限制时不主动耗尽剩余请求体。临时目录使用受根目录约束的句柄并拒绝静态链接，测试覆盖互不干扰、解析截断、限额和越界路径。

Windows 本机 Go 全量测试与 vet 通过，Linux 交叉编译通过。组件**没有接入上传 HTTP 路由**；鉴权优先、MIME 内容识别、正式对象写入、数据库事务、未知提交补偿及真实跨机器联测均未完成。请求目录的静态检查不承诺抵御有本机写权限者并发替换，临时目录需要适当的操作系统权限。临时清理失败记录固定信息，仍可能产生待处理残留。

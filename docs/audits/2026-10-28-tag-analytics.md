# 2026-10-28 标签统计隐私修复与原生接口

Nuxt 原标签统计视图未按访问者过滤内容，且对删除帖的计数可能不准确。三端改为对当前会话用户可见、未删除的帖子进行聚合；没有可见帖时保留标签并返回零值。名称先 URL 解码并作为参数绑定。该修复会改变此前包含不可见内容的统计值。接口禁用响应缓存，Nuxt 对所有包含帖子可见性函数的查询禁用查询缓存，避免旧权限结果；单后端缓存模式下相关查询命中率因此下降。

三端共同隔离场景覆盖会话、Cookie 优先、名称、缺失、错误、零结果和返回字段。SQL 替身检查查看者参数与可见性条件；Nuxt 测试两个查看者的不同模拟结果，并测试单后端模式下两层缓存均绕过。这些测试不证明真实 Oracle 函数、聚合、事务快照、性能或实际跨账号隔离；上述项目、跨后端和前端仍需独立环境联测。本轮未启动 Docker、真实服务或模型，未修改日常数据。

Nuxt 全量隔离测试 539 通过、2 跳过，类型检查通过；Go 全量 test/vet 通过，并对响应缓存标头补充专项测试；Rust WSL 离线全量回归通过、2 项真实依赖测试忽略，随后对响应缓存标头补充专项测试。

# Nuxt 聊天共享连接

2026-11-13 聊天页与通知复用应用级实时连接。频道加入和离开等待经过当前用户校验的状态帧。连接恢复后重新加入当前频道，并读取聊天历史及私信。会话或端点变化会清除页面的群、频道和私信状态，阻止旧读取和发送结果覆盖当前页面。附件上传过程中切换会话或频道时停止后续发送。

Nuxt 服务端将入站命令按连接和接收顺序串行处理。加入命令即使仍在等待鉴权，随后收到的离开命令也会在它处理完毕后执行。第 17 条待处理命令关闭该连接并释放订阅。35 项隔离回归覆盖就绪门槛、会话切换、频道命令顺序及积压关闭，四目录 parity 检查通过。共享契约仍为第 4 版。

真实浏览器中的频道切换和恢复仍待验收。Flutter 活动聊天页的端点切换与 Rust、Go 原生实时聊天和私信仍在进行。

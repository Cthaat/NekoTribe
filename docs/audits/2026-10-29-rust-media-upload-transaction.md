# Rust 媒体上传事务开发检查点

Rust 使用单连接媒体上传事务：取得媒体序列、检查媒体结构、插入 ready 记录、读取并映射结果后提交。预提交失败且确认回滚时可清理该请求对象；回滚失败或提交已开始后返回不安全清理状态。预提交的结构不可用映射为共同接口的 503 错误。

事务边界通过内存事务替身测试，覆盖序列、结构、写入、读取、响应映射、回滚及提交失败；Oracle 适配器未使用真实数据库验证。`SessionRepository`、`SessionExecutor` 和 Oracle 连接池现已接入事务：在提交前将媒体响应中的文件及缩略图地址按存储配置映射；连接、后台任务或关闭连接异常通过仓储错误返回，调用方必须按提交结果未知保留对象。仓储委托和地址映射有定向替身测试。

WSL Rust 全量离线回归通过，两个真实依赖测试维持忽略；不代表实际 Oracle 事务或断连已验收。

Rust 流式 multipart 解析通过匿名临时文件保存上传内容，限制单文件、总文件、字段、请求总量及 part 数量，按 `file` 优先、`media` 备选选择第一个文件。定向测试覆盖优先级、第一字段、超限、截断和文件读取位置；路由在调用前先鉴权。请求总量比文件与字段限额多允许 10 MiB 用于边界和头部，与其他实现的极端头部行为尚需统一；Windows 临时文件行为尚未实测。

引入 `multer` 与 `tempfile` 后，WSL Rust 全量离线回归通过；真实 Oracle/Redis 测试仍被忽略。

新增基于 `infer` 的 4 KiB 内容前缀识别：共同简单签名样例通过，包含伪装文本的可执行文件；流式临时文件读取后恢复到开头。PNG 检查按块跳读，支持前 4 KiB 之外的 APNG 标记，限制文件大小、块大小和块数量，共同的大 PNG/APNG 样例及异常长度测试通过。PNG 检查要求完整块，可能比 Nuxt/Go 对截断内容更严格，尚需统一。

ZIP 检查可读取受限目录和本地头、区分普通 ZIP、DOCX、ODT、JAR 等，共同样例及损坏的本地头测试通过；ZIP64、分卷、加密、超限目录和不支持的压缩或元数据按错误处理。目录和本地头的标志、方法、名称、校验值及大小现在进行一致性检查，目录标志、校验值、分卷标记和长度异常的测试通过。更多 Office 变体、文件签名、ZIP 畸形样例和其他复杂容器仍需共同验证，尚不能证明与 Nuxt 完全一致；未知结果也不能证明安全。

`POST /api/v2/media` 已接入原生鉴权、解析、检测、本地发布及事务；隔离路由测试覆盖成功、错误请求、可执行文件伪装、不支持的 S3、确认回滚、结构不可用与提交不确定。图片尺寸从最多 4 MiB 的前缀中读取，PNG 实际上传、JPEG/GIF/WebP/AVIF 独立样例已测；无法解析时保留空值。此次 WSL Rust 全量离线回归通过，真实依赖测试仍忽略。音视频元数据尚未实现，4 MiB 之后才出现的图片元数据可能无法读取。数据库使用替身，不能作为完整原生上传或真实 Oracle 验收的证据。异步任务取消或超时可能产生孤立对象，不能默认安全清理。

已增加 Rust 本地文件发布组件：服务器生成按 UTC 年月分桶的 UUID 存储键，以受限目录句柄创建临时副本并硬链接发布，现有目标不会被覆盖。使用请求独立暂存目录（Unix 权限 0700），持有目录和文件身份，并在发布及清理前检查；WSL 定向测试覆盖文件和目录被替换时保留其他对象、重名和目录符号链接，Rust 全量离线回归通过。检查与硬链接或删除之间仍存在竞争窗口，本机特权并发场景未证明安全。

发布后保留文件身份和目录句柄；事务结果明确允许清理时才核对目录及文件身份并删除。确认提交、提交不确定或仓储错误时保留对象；文件或目录被替换时也保留。事务结果与真实临时文件的替身联动测试及 Rust 库级回归通过；检查与删除之间仍存在竞争窗口。

还需补齐元数据、格式差异、取消后的孤立对象对账、暂存目录创建及替换的竞争保护和 Windows 行为验证；目标文件系统须支持硬链接，不能据此宣称发布流程已完成。

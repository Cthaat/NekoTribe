# Rust 媒体上传事务开发检查点

Rust 新增单连接媒体上传事务组件：取得媒体序列、检查媒体结构、插入 ready 记录、读取并映射结果后提交。预提交失败且确认回滚时可清理该请求对象；回滚失败或提交已开始后返回不安全清理状态。预提交的结构不可用单独标记，调用方仍须将其映射到共同接口错误。

事务边界通过内存事务替身测试，覆盖序列、结构、写入、读取、响应映射、回滚及提交失败；Oracle 适配器未使用真实数据库验证。`SessionRepository`、`SessionExecutor` 和 Oracle 连接池现已接入事务：在提交前将媒体响应中的文件及缩略图地址按存储配置映射；连接、后台任务或关闭连接异常通过仓储错误返回，调用方必须按提交结果未知保留对象。仓储委托和地址映射有定向替身测试。

WSL Rust 全量离线回归通过，两个真实依赖测试维持忽略；不代表实际 Oracle 事务或断连已验收。

Rust 已新增独立的流式 multipart 解析组件：通过匿名临时文件保存上传内容，限制单文件、总文件、字段、请求总量及 part 数量，按 `file` 优先、`media` 备选选择第一个文件。定向测试覆盖优先级、第一字段、超限、截断和文件读取位置；该组件要求调用方先鉴权，尚未接入路由。请求总量比文件与字段限额多允许 10 MiB 用于边界和头部，与其他实现的极端头部行为尚需统一；Windows 临时文件行为尚未实测。

引入 `multer` 与 `tempfile` 后，WSL Rust 全量离线回归通过；真实 Oracle/Redis 测试仍被忽略。

新增基于 `infer` 的 4 KiB 内容前缀识别：共同简单签名样例通过，包含伪装文本的可执行文件；流式临时文件读取后恢复到开头。PNG 检查按块跳读，支持前 4 KiB 之外的 APNG 标记，限制文件大小、块大小和块数量，共同的大 PNG/APNG 样例及异常长度测试通过。PNG 检查要求完整块，可能比 Nuxt/Go 对截断内容更严格，尚需统一。

这些能力尚未接入路由。ZIP 检查现可读取受限目录和本地头、区分普通 ZIP、DOCX、ODT、JAR 等，共同样例及损坏的本地头测试通过；ZIP64、分卷、加密、超限目录和不支持的压缩或元数据按错误处理。目录和本地头的标志、方法、名称、校验值及大小现在进行一致性检查，目录标志、校验值、分卷标记和长度异常的测试通过。引入 ZIP 依赖后 WSL Rust 全量离线回归通过；本轮 Rust 库级回归 43 项通过，真实依赖测试未验收。更多 Office 变体、文件签名、ZIP 畸形样例和其他复杂容器仍需共同验证，尚不能证明与 Nuxt 完全一致；未知结果也不能证明安全。

文件发布及 HTTP 路由仍未接入，不能作为 Rust 原生上传已完成的证据。后续调用方还需处理异步任务取消及超时导致的未知结果，不能默认对象可清理。

已增加 Rust 本地文件发布组件：服务器生成按 UTC 年月分桶的 UUID 存储键，以受限目录句柄创建临时副本并硬链接发布，现有目标不会被覆盖。使用请求独立暂存目录（Unix 权限 0700），持有目录和文件身份，并在发布及清理前检查；WSL 定向测试覆盖文件和目录被替换时保留其他对象、重名和目录符号链接，Rust 全量离线回归通过。检查与硬链接或删除之间仍存在竞争窗口，本机特权并发场景未证明安全。

发布后现保留文件身份和目录句柄；事务结果明确允许清理时才核对目录及文件身份并删除。确认提交、提交不确定或仓储错误时保留对象；文件或目录被替换时也保留。事务结果与真实临时文件的替身联动测试及 Rust 库级回归 53 项通过。尚未接到 HTTP 路由，检查与删除之间仍存在竞争窗口。

还需补齐取消后的孤立对象对账、暂存目录创建及替换的竞争保护和 Windows 行为验证；目标文件系统须支持硬链接，不能据此宣称发布流程已完成。

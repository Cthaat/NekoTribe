# Go 原生媒体上传路径检查点

Go `POST /api/v2/media` 已连接 access 会话校验、请求专属流式暂存、内容识别、类型选择、本地原子发布与媒体数据库事务。数据库回滚确认时仅清理该请求创建的对象，提交结果不确定或回滚失败时保留；清理期间保持文件句柄并核对对象身份。PNG/JPEG/GIF 使用 Go 标准库尝试读取尺寸；WebP 使用 `golang.org/x/image/webp` 读取尺寸，有损及无损样例通过上传路径隔离测试；失败时返回空元数据。S3 配置明确返回未实现。

隔离测试使用真实 multipart、临时文件和数据库驱动替身，覆盖成功、未登录、无效内容、截断、结构检查失败、插入失败、回滚失败、提交异常、图片尺寸和对象替换保护。Windows Go 全量测试与 vet 通过；WSL Linux ext4 上传与对象替换隔离测试通过。数据库替身不证明真实 Oracle 提交、跨后端或另一台服务器行为。

该路径仍在开发中：AVIF 的尺寸及音视频尺寸/时长尚未实现；WebP 更多变体尚需共同样例；Go 探测器和 Nuxt `file-type` 对全部真实格式尚未证明一致；ZIP64、分卷、特殊容器和超限元数据被拒绝，某些扩展名比 Nuxt 限制更严；硬链接发布要求同一支持硬链接的文件系统。共享对象引用、私密附件授权、恶意文件检查和高权限本机并发替换防护仍需后续完成。Rust 尚未接入上传。

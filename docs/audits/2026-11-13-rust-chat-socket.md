# Rust 频道与私信实时接收

2026-11-13，Rust 原生 `/_ws` 已接入共享频道加入和离开命令，以及当前用户频道上的私信事件。Oracle 查询沿用 Nuxt 的群状态、成员状态和私密频道角色条件。转发频道事件前检查当前会话和成员权限，失权后释放该频道。离开再加入时丢弃前一订阅已入队的事件。私信保留原始 JSON，校验会话标识及消息标识。

每连接最多登记 64 个频道，频道转发队列最多 16 条，队列溢出结束连接。与 Go 一样，每个频道订阅占一个 Redis Pub/Sub 连接，与通知订阅共用 1024 个适配器槽位。集中验收需测量连接容量和频道独立断线时的状态反馈。

离线测试覆盖 Rust lib、notification_websocket、notification_source、local_presence 和 settings_presence，118 项通过、1 项既有 ffprobe 用例忽略。回环测试覆盖无权加入、频道不匹配、私信接收及失权释放。四目录对齐检查通过。Rust、Go 原生聊天和私信 HTTP 操作、本地分发、提交后发布及真实依赖验收仍待推进。共享契约维持第 4 版，accepted=0、ready=false。

# Go 大型媒体容器识别检查点

Go 增加对请求暂存文件的随机读取检查，允许识别探测标识位于 4096 字节之后的普通 ZIP、DOCX、ODT、JAR 和 PNG/APNG。六个相同字节的构造样本分别由 Nuxt `file-type` 和 Go 检查并通过；JAR 和 APNG 按现有媒体白名单仍不作为支持类型。原仅依靠 4096 字节的读取器继续对信息不足的容器明确拒绝，文件型检查是独立增量，尚未连接上传路由。

ZIP 检查限制中央目录 4 MiB、10000 项、单项元数据解压 1 MiB，并拒绝 ZIP64、分卷、异常间隙、损坏描述符和本地/中央目录名称不一致；常见流式描述符通过隔离测试。PNG 分块检查限制最多 10000 块并支持取消。为限制资源和规避错误识别，这些限制比 Nuxt 更严格；其他真实 ZIP 变体、恶意输入、跨平台与完整格式覆盖仍需验证。此组件不扫描恶意文件，也不代表上传、真实 Oracle 或 Rust 内容探测已完成。

本轮 Go 全量测试与 vet、Nuxt 的 20 项内容/容器样例、共同需求和 OpenAPI 副本检查通过；这些均为隔离验证。

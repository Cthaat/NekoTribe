# Go 原生媒体删除检查点

Go 已接入 `DELETE /api/v2/media/{id}`：校验 access 会话后，以当前用户和媒体 ID 读取、删除记录；数据库确认恰好一行提交并关闭连接成功后才清理受管理的本地文件。无记录或并发零行返回 404，数据库错误或异常行数不会执行文件清理。对象地址优先使用 storage key，缺失时仅使用本地相对路径或配置的同源公开地址，其他来源不删除。S3 为未实现，不能回退本地。

隔离测试覆盖身份、所有权绑定、零行竞争、数据库查询/写入/提交错误、数字 ID、受管理地址、路径穿越、静态链接和本地文件清理。Go 全量测试及 vet 通过；无需启动 Nuxt、Oracle、Redis 或 Docker。真实 Oracle 外键、并发和不确定提交，以及跨后端共同场景尚未验收。已提交数据库删除后，存储清理失败可留下孤立文件；共享对象引用与读取后记录改变仍需完整机制。根目录句柄限制越界，但具有本机写权限者并发替换目录的隔离仍需进一步验证。

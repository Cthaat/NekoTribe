# 2026-10-27 登录头像公共地址检查点

三套后端按照共同的公共地址规则处理登录响应中的头像：支持配置公共路径、应用地址或 CDN 地址，并迁移常见旧存储路径。共同要求和 26 条合成样例分别见 [规格](../../specifications/requirements/storage-public-urls.md) 和 [样例](../../specifications/scenarios/storage-public-urls.json)。配置中的公开基础 URL 不允许包含用户名或密码；公共路径不允许 `/`、全斜杠或以 `//` 开头，避免凭据进入响应或地址指向错误主机。使用这些配置的既有部署需要先调整配置。

- Nuxt：26 条地址样例通过，完整测试 444 通过、2 跳过，类型检查通过。
- Go：共同样例、登录响应与不安全配置测试以及完整 `go test ./...`、`go vet ./...` 通过；Windows 和 Linux amd64 构建通过。
- Rust：共同样例、登录响应与不安全配置测试以及 WSL Linux 的完整离线测试通过；2 项依赖真实服务的测试按原有设置跳过。
- 公共规格和样例在三个工程中的一致性检查通过；未因此将任一功能标记为业务验收完成。

本检查点只覆盖 URL 转换和隔离登录响应，不证明文件存在，也不证明 Rust/Go 的文件读取、上传、删除或通知业务完整。标准 URL 之外的非标准和畸形输入可能存在语言库差异；真实数据库、CDN、浏览器跨机器访问以及 Windows 原生 Rust 构建仍需单独验证。本轮未启动真实应用、数据库、Docker 或模型。

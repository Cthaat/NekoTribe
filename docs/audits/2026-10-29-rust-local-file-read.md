# Rust 原生公开文件读取检查点

Rust native 已接入 `GET /storage/...`，使用 `STORAGE_PATH`、`STORAGE_ROOT_DIR`（依次优先）或当前工作目录的 `storage`；S3 配置明确返回未实现。文件读取复用共同 key/Range 规则，拒绝暂存目录、目录和静态链接，并分块流式返回；缺省头像沿用 Nuxt 内置回退。compat 模式继续使用原有代理。

隔离 HTTP 测试覆盖完整与范围读取、越界、空文件、路径穿越、静态符号链接、S3 拒绝，以及通过原生应用路由读取配置目录而不依赖 Nuxt。上传/删除、私密附件授权和真实共享数据、Windows 与跨机部署仍未完成。Rust 检查 Windows reparse 标记但尚未在 Windows 原生运行验证；检查与打开之间仍有本机并发替换风险，未使用根目录约束句柄，生产部署需配合文件系统权限并继续强化。

WSL Linux 下 Rust 全量离线回归通过；其中依赖真实外部环境的既有测试仍按原设置忽略。四工程共同需求和 OpenAPI 检查通过；它们不代替真实业务验收。

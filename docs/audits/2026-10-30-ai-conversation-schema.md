# AI 对话存储结构开发检查点

已在显式迁移计划中登记 `N_AI_CONVERSATIONS`、`N_AI_MESSAGES` 和会话所有者索引；会话和消息使用 UUID，消息顺序在同一会话内唯一，并通过外键级联删除。目的、用户归属、可选群标识、角色、模型标识/版本和配置版本是为后续授权、多轮对话及模型切换预留的数据；不包含模型凭据。共同边界见 `specifications/requirements/ai-conversation-storage.md`。

隔离迁移测试覆盖缺失对象创建、结构检查、重复执行和原有设置数据不变；未连接 Oracle，尚未执行实际迁移。两套后端的共享目录已重新生成并同步，包含新迁移的账本校验值；旧版本原生后端可能因不认识新账本记录而拒绝结构检查，部署时须先更新三后端代码及目录，再由管理员显式执行迁移，不能在运行中的旧版本混部时假定兼容。

Nuxt、Go 和 Rust 已新增内部会话创建/读取组件：服务端生成 UUID、按所有者查询，群会话使用现有群管理员权限函数、审核会话依据现有审核账号规则；创建事务在提交前再次检查权限，失败回滚，提交结果未知时不假定回滚。Nuxt 还严格限定请求字段，Go 和 Rust 组件当前接收内部类型，公开接口解析及运行时授权配置接线仍待实现。测试使用存储和权限替身，覆盖群权限撤销；Go 和 Rust 结构检查通过共同就绪样例。Rust 离线库测试 67 项通过、1 项因缺少 ffprobe 忽略，结构检查测试 12 项通过；未连接真实 Oracle。

当前模型记忆、知识库、Skills 和客户端入口尚不可用。后续必须在真实业务鉴权后实现会话列表与删除、完整消息事务追加、并发顺序、群管理员失权、数据删除/保留、工具历史与模型切换，并使用隔离 Oracle 和真实客户端验收。

后续增量：Nuxt、Go 和 Rust 已实现内部用户消息追加，按 UTF-8 字节限制内容，锁定所属会话并在事务中分配序号、写入与更新会话时间，提交前重新检查权限。隔离测试覆盖长度和权限撤销；Go 还覆盖序号上限、连续追加与插入失败，全量离线测试和 vet 通过。Rust 使用临时 CLOB 绑定消息，避免其驱动将普通字符串绑定为 NVARCHAR2。测试替身不证明真实并发锁或 Oracle CLOB 写入。

Nuxt、Go 和 Rust 新增内部消息历史读取：按序号分页，读取前和返回前复核权限，读取正文及模型元数据。隔离测试覆盖分页和读取期间群权限失效；Nuxt/Go 还覆盖跨账号拒绝，Go 全量离线测试和 vet 通过，Rust 库测试 72 项通过、1 项因缺少 ffprobe 忽略，结构检查测试 12 项通过。工具历史恢复、真实 CLOB 和跨后端访问尚未完成。

Nuxt、Go、Rust 均已接入创建会话、读取会话、追加用户消息、读取消息历史四个 HTTP 路由，要求登录，响应标记 private/no-store；`/api/v2/ai` 路径及子路径在 Nuxt 的任何缓存模式下绕过响应缓存，避免私密对话正文和变更后的授权状态被缓存复用。隔离测试覆盖登录、输入与缓存边界，Go 全量离线测试及 vet 通过；三端尚未通过真实 Oracle 和客户端端到端测试，部分固定错误文案及非 JSON 请求行为仍须对齐。

Nuxt、Go、Rust 增加内部助手回复写入：记录 profile ID 与配置版本，并在锁定会话时检查预期序号，拒绝旧上下文生成结果。隔离测试覆盖元数据、序号冲突和群权限撤销；Go 全量离线测试及 vet 通过，Rust 库测试 74 项通过、1 项因缺少 ffprobe 忽略，AI 路由 3 项及结构测试 12 项通过。三端完整模型调用编排和真实 Oracle 验证仍未完成，客户端不能直接写入助手角色。

此前增量：Nuxt、Go 已接入写作生成入口 `POST /api/v2/ai/conversations/{id}/generate`，从服务端配置选择模型，读取最近的有权访问的会话历史，释放数据库连接后调用推理服务，再以预期序号保存助手回复。模型失败、截断或会话冲突不保存成功回复。回环假提供方测试验证了实际推理传输；真实模型及 Oracle 尚未验收。此入口不提供知识库、工具执行、群运营或审核助手；当时 Rust 和客户端尚未实现对应生成流程。配置说明见 `docs/ai-writing-development.md`。

安全修复：AI 请求绕过 Oracle 查询缓存，AI 会话表和群权限函数查询在其他请求中也不缓存，避免私密正文或失效授权结果被复用。隔离测试覆盖启用单后端缓存模式。

后续增量：Rust native 已接入同一有限写作生成接口，使用进程启动时读取的模型配置；回环假提供方和仓储替身测试覆盖生成、鉴权、用途限制、序号冲突与截断。真实 Oracle、真实模型、客户端及端到端模型切换仍待验收；知识库和 Agent 也尚未实现。

Flutter 新增写作页面和 API 客户端，通过现有端点配置访问所选后端；隔离 UI 测试覆盖发送、生成失败重试和提交结果不确定时的刷新。当前页面关闭后尚不能恢复对话，真实后端联调和客户端其他 AI 产品能力仍待实现。

后续存储增量：Nuxt、Rust、Go 已增加内部删除会话事务，锁定当前用户拥有的会话、删除前后复核当前群或审核权限，并依赖已登记的外键级联删除消息。隔离测试覆盖权限撤销与提交边界；真实 Oracle 的级联和并发尚未验证。这一增量尚未接入 HTTP，也没有会话列表，因此客户端尚不能删除或恢复历史会话。

后续接口增量：三端已接入 `DELETE /api/v2/ai/conversations/{id}`，要求登录并返回私密无缓存响应；Flutter 当前写作会话可经确认后删除。会话列表和跨设备恢复仍未完成，真实数据库、模型及跨后端端到端测试仍待执行。

会话恢复增量：已定义三端统一的会话列表游标和权限规则，并在 Nuxt 内部实现列表读取；隔离测试覆盖用户范围、权限撤销、拒绝泄露无权会话的游标及权限查询失败。Rust、Go 的列表实现、公开接口和客户端恢复仍待接线，真实 Oracle 查询及并发权限变更也尚未验收。

后续增量：Go 已实现内部会话列表事务与相同的授权分页规则，并使用事务和数据库驱动替身验证所有者限定、权限失败和游标处理；Rust 列表、HTTP 接口以及真实数据库验收仍未完成。

后续增量：Rust 已实现内部会话列表查询、权限复核和相同的可见游标规则，隔离存储测试覆盖权限撤销和错误边界。三端列表仍未接入公开 HTTP，客户端恢复和真实 Oracle 验收待完成。

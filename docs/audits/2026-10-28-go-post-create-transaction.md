# Go 原生发帖事务仓储检查点

Go 新增内部 `CreatePostAtomic` 仓储。它校验帖子类型和引用、检查原帖可见性，在同一插入语句复核原帖状态；单事务写入帖子、前四个去重媒体、标签和提及，媒体限定作者与可用状态。无文字和媒体的普通帖子拒绝，空转发允许；提交前失败执行回滚，回滚失败返回内部错误，提交错误的实际结果不作推断。通知与最终读取不在该事务中。

隔离 SQL 驱动测试覆盖不可见引用、插入时权限变化、媒体不可用、标签和提及失败、回滚和提交失败、去重和数量边界、空内容及空转发；Go 全量测试和 vet 通过。测试不证明实际 Oracle 绑定、触发器、事务、锁、并发或未知提交状态。

当前仓储尚未接入 HTTP 请求、客户端输入转换、帖子响应、回复/转发/提及通知和 Redis；Rust 发帖也未实现。共同功能仍 `in-progress`，不声称 Go 发帖接口已可用。下一步完成上述接线和共同场景，再做真实隔离验收；本轮未启动 Docker 或访问日常数据库。

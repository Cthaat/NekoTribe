# AI 知识来源实时复核开发检查点

Nuxt 已增加内部来源复核组件：索引候选只含类型、ID、版本，从业务表重新读取公开且当前可见的帖子或评论，检查正文版本后才返回；对已删除、改权或内容变化的候选不回退到旧索引正文。查询直接使用连接，绕开通用查询缓存，正文读取前限制 CLOB 字符数，返回前再限制 UTF-8 字节数。共同要求和跨语言版本向量已同步到 Rust/Go。

隔离测试覆盖指纹向量、公开和用户权限 SQL、内容变更、无效候选及异常数据。这一组件尚未接入索引、模型或公开接口，Rust/Go 尚未实现。公开群内容、平台规则、索引构建和失效、推理后再次复核、真实 Oracle 与跨后端验收仍需完成；不能将其称为知识库或问答已可用。

后续增量：Go 已实现相同的内部来源复核与指纹规则，数据库驱动替身测试检查当前用户参数、公开状态、删除状态、正文长度和评论父帖子约束。Nuxt 与 Go 同时收紧了帖子来源 ID 必须等于所属帖子 ID 的异常检查。Rust 和真实数据库联调仍待完成。

后续增量：Rust 已实现相同的内部来源复核、SQL 过滤和版本规则，共享指纹向量与候选校验使用隔离测试；真实 Oracle 驱动的 CLOB 和权限函数仍待验证。三端组件尚未连接索引或生成流程，也未实现生成完成后的来源再次检查。

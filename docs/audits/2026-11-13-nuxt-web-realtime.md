# Nuxt Web 通知连接

2026-11-13 已接入共享 WebSocket 第 4 版的状态帧。连接对象和监听器按 Nuxt 应用归属。会话修订、用户或端点变化时立即丢弃旧连接，定时器和回调只作用于原连接。旧服务及断线时显示 unknown 状态。合法降级状态触发本地化提示，恢复后通知列表重新执行读取。列表在账号或端点变动时清空，已失效的请求结果会被丢弃。

124 项 Node 隔离测试通过，含共享向量、当前用户校验、同账号重登、切换端点、多应用隔离、断线恢复与显式停止重连。类型检查和四目录对齐状态记录在 [验证记录](../../../docs/handoff/VALIDATION-LATEST.json)。真实浏览器提示和通知列表恢复尚待验收，Flutter 与 Nuxt 聊天页的独立 WebSocket 仍待接入。

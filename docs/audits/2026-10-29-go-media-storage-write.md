# Go 媒体正式对象写入检查点

Go 已增加与请求暂存组件配套的本地对象写入：服务端生成用户、UTC 年月与 UUID 组成的 key，父目录逐级检查，目标文件排他创建，内容以有界缓冲区流式复制；已有文件不覆盖。请求取消或复制失败时尝试只清理本次创建且身份仍匹配的对象；暂存源保留给后续数据库事务决定何时清理。

隔离测试覆盖路径、UTC 日期、存储根一致性、S3 拒绝、链接目录、已有对象不覆盖，以及复制过程中取消后的部分文件清理。Go 全量测试和 vet 通过。该组件**尚未接入上传接口或数据库事务**，类型识别和提交不确定时的补偿仍待实现。目标文件在复制完成前即存在于公开存储目录中，临时可见性需要在完整上传流程中进一步解决；目标文件身份无法确认或清理失败时可能留有孤立对象。高权限本机并发替换的完整隔离和跨机器、真实文件系统验证仍待完成。

后续修正：Go 写入现在先在请求暂存目录完成复制，关闭文件后用硬链接原子创建正式路径，复制中的正式地址不可见；链接失败或目标已存在时不覆盖、不回退为公开复制。该方案要求暂存与正式目录位于同一支持硬链接的文件系统；跨文件系统或不支持硬链接会明确失败，需在部署验证和配置中处理。Windows 本机及 WSL Linux 的 ext4 临时目录隔离测试覆盖可见性、冲突、取消和暂存清理；另一台机器、不同挂载和不支持硬链接的实际环境尚未验收。

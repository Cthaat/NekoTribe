# Go 本地公开文件读取检查点

Go 已接入 `GET /storage/...`，读取目录由 `STORAGE_PATH`、`STORAGE_ROOT_DIR`（依次优先）或当前工作目录下 `storage` 配置；配置 S3 时明确返回未实现，不回退本地。复用共同 key 和 Range 规则，拒绝暂存目录、目录和静态符号链接，使用 Go 根目录约束的文件句柄与流式读取；缺省头像沿用 Nuxt 的内置回退。

临时目录 HTTP 测试覆盖完整与部分读取、空文件和越界 Range、路径穿越、目录、暂存目录、符号链接及 S3 拒绝；Go 全量测试和 vet 已通过。真实跨机器、私密附件授权、对象上传/删除、实际共享数据库以及 Rust 原生文件读取仍未完成。根目录句柄限制越界，但静态链接检查和打开之间对有本机写权限者的并发替换并非完整隔离；上线需结合系统权限和平台级隔离验证。公开读取不可作为私密附件授权。

同时修正 AI 需求：保留独立 Python 服务与逐步迁移旧情感分析功能同时成立；现有服务和模型数据没有删除。规范副本通过共同检查后同步，AI 产品及真实模型仍未验收。

# 当前用户资料原生切片

Go 与 Rust 原生模式新增 `GET /api/v2/users/me`，以当前 access token 和数据库 session 验证的用户 ID 查询资料，复用已有 self profile SQL 与头像公共地址规则；Nuxt 当前用户资料入口对内部异常做安全收口，并绕过 Nuxt 响应缓存，防止其他后端修改共享数据后读到该缓存中的过期资料。

三端共享 10 条合成场景，覆盖 Cookie 与 Bearer、缺失/过期令牌、Cookie 优先、失效会话、数据库错误、资料缺失和忽略指定其他用户的 query。Nuxt 使用实际路由/会话中间件及资料映射函数，Oracle 和其他边界使用替身；Go/Rust 检查真实路由、模拟 session 和资料仓储，并检查头像公共地址配置及不泄露凭据。OpenAPI 更新了资料空值、在线状态、Cookie 鉴权和两种错误传输。

目前没有对 Oracle 视图、关系函数、日期时区、跨实例资料变更或两个客户端进行真实联测；这不是完整后端验收。其他用户接口和缓存的跨后端一致性仍需逐项开发与验证。本轮不启动 Docker、真实应用、数据库或模型。
